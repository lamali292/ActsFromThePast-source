# Acts From The Past (source)

Source code of the **Acts From The Past** mod for Slay the Spire 2, published for reference.

This repository contains the C# code, project files and build scripts only. It intentionally does **not** contain any art, audio, animations, localization or other game assets, so it cannot be built into a working mod as-is.

Get the mod on the [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3839934327).

Every release is exported here as a single commit tagged with the version. There is no development history, and pull requests are not accepted.
